Markdown

What Preview understands

Type these in a note - nothing fancier is needed.

  • # ## ### headings
  • **bold**
  • *italic* or _italic_
  • ~~strike~~
  • `code`
  • [label](https://…) links
  • - item bullets
  • 1. item numbered
  • - [ ] / - [x] tasks
  • > quote
  • #tag
  • --- rule
